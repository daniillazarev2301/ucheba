Ucheba — мини‑сайт установки

Пошаговая установка проекта на Ubuntu VDS и объяснение, где находятся сервисы и данные.

1. Подготовка сервера

sudo -i
apt-get update
apt-get install -y git curl

2. Введите параметры установки

Сайт формирует готовую команду установки. Данные никуда не отправляются — генерация локальная в браузере.

Нажмите «Сгенерировать команду»

3. Запуск установки

cd /opt
rm -rf /opt/ucheba

git clone "$REPO_URL" "$PROJECT_DIR"
cd "$PROJECT_DIR"

bash scripts/install_vds.sh

4. Где находятся данные

PostgreSQL

Данные БД по умолчанию: /var/lib/postgresql/14/main (может отличаться по версии).

Redis

База Redis: /var/lib/redis, конфиг: /etc/redis/redis.conf.

Проект

Код проекта: /opt/ucheba, статика: /opt/ucheba/backend/staticfiles, медиа: /opt/ucheba/backend/media.

Логи

Системные логи сервисов: journalctl -u ucheba-gunicorn.

5. Как происходит соединение с сервером

Подключение выполняется по SSH. Вы подключаетесь к VDS и запускаете сгенерированные команды. Автоустановщик не выполняет удалённых запросов сам — соединение инициирует администратор с вашей машины.

6. Проверка сервисов

systemctl status ucheba-gunicorn
systemctl status ucheba-celery
systemctl status ucheba-bot

7. SSL (по желанию)

apt-get install -y certbot python3-certbot-nginx
certbot --nginx -d example.com

8. Установка через GitHub Pages

Если публикуете архив на GitHub Pages, используйте:

export PAGES_URL=https://example.github.io/ucheba
export ARCHIVE_NAME=ucheba.tar.gz

curl -fsSL https://example.github.io/ucheba/install_from_pages.sh | bash
